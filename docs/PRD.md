# 流量台 Glassmeter · 产品需求文档（PRD）

## 1. 产品定位

一个自托管的网站流量监测平台：站点所有者在平台上创建站点，拿到一段 JS 埋点代码，嵌入自己的网页后，即可在平台看板查看访问数据。

- 形态：Web 应用，前后分离（前端 SPA + 后端 API + 独立埋点 SDK）
- 视觉：黑白单色（深浅双主题）+ 玻璃拟态，**不使用任何 emoji 与图标**
- 本期范围：基础流量指标 + 来源与设备分析

## 2. 用户角色与核心流程

只有一个角色：**站点所有者**（注册用户，可管理多个站点）。

核心流程：

1. 注册 / 登录
2. 新建站点（填写名称 + 域名）→ 生成站点公钥（`pk_live_xxx`）
3. 复制平台给出的埋点代码，粘贴到自己网站 `<head>` 中
4. 访问者打开站点 → SDK 自动上报 → 平台看板出数据

## 3. 功能范围

### F1 账号体系

- 邮箱 + 密码注册、登录；JWT 鉴权（Bearer Token），Token 存 localStorage
- 登录态失效（401）自动跳转登录页
- 登出
- 密码使用 bcrypt 哈希存储，不落明文

### F2 站点管理

- 站点列表（卡片式）：名称、域名、公钥、创建时间
- 新建站点（弹窗）：名称必填，域名必填（仅用于展示与来源识别，不做校验拦截）
- 删除站点（二次确认），级联删除该站点全部访问数据
- 查看 / 复制埋点代码：
  
  ```html
  <script defer src="<平台地址>/tracker.js" data-site="pk_live_xxxxxxxx"></script>
  ```

### F3 埋点采集 SDK（tracker.js）

- 纯原生 JS，无依赖，体积目标 < 8KB（未压缩）
- 单文件、无构建：`tracker/tracker.js` 为唯一源码即发布物，由后端 `GET /tracker.js` 直接托管
- 通过 `<script data-site="公钥">` 自动初始化，无需额外配置代码
- 采集内容：
  - 页面浏览事件 `pageview`（每次进入 / SPA 路由切换各记一次）
  - 心跳事件 `pulse`（页面可见时每 15s 一次，用于会话时长估算）
- 自动能力：
  - 访客 ID：localStorage 持久 UUID
  - 会话 ID：sessionStorage UUID，30 分钟无活动自动新开会话
  - SPA 支持：劫持 `history.pushState / replaceState` + 监听 `popstate`
  - 上报方式：优先 `navigator.sendBeacon`，降级 `fetch(keepalive)`
  - 不采集任何用户输入内容、不写 Cookie

### F4 数据看板 · 基础指标

选定站点 + 时间范围（今天 / 近 7 天 / 近 30 天）后展示：

| 模块 | 内容 |
| --- | --- |
| 指标卡 ×5 | PV、UV、会话数、跳出率、平均会话时长；每张卡带环比（对比上一等长周期） |
| 趋势图 | 按天折线/面积图，可切换 PV / UV / 会话 三条序列，带网格、悬停提示 |

指标口径见第 4 节。

### F5 来源与设备分析

| 模块 | 内容 |
| --- | --- |
| 来源渠道 | 渠道分类占比（环形图 + 排行列表）：直接访问 / 搜索引擎 / 社交媒体 / 外链引荐 / 站内跳转 / 营销活动(UTM) |
| 引荐域名 | Top 引荐来源域名排行（条形列表） |
| 浏览器 | Chrome / Edge / Firefox / Safari / 微信 / 其他 占比 |
| 操作系统 | Windows / macOS / iOS / Android / Linux / 其他 占比 |
| 设备类型 | 桌面 / 手机 / 平板 占比 |
| 屏幕宽度 | 分桶：<576 / 576–992 / 992–1440 / >1440 |

### F6 页面排行

- Top 页面列表：路径、PV、UV、平均停留时长（按会话末次事件−首次事件估算，同页面近似）

### F7 主题与设计系统

- 深色 / 浅色主题切换，持久化到 localStorage，默认跟随系统 `prefers-color-scheme`
- 黑白单色体系（详见 [DESIGN.md](./DESIGN.md)）
- 玻璃拟态六效果必须完整落地：**折射、反射、边缘、边缘泛光、光晕、按压（按压点涟漪 + 微扭曲）**

### F8 演示数据

- 提供 `python -m app.services.seed`：创建演示账号 + 演示站点 + 近 30 天模拟访问数据，便于零配置查看完整看板

## 4. 指标口径定义

| 指标 | 定义 |
| --- | --- |
| PV | `pageview` 事件总数 |
| UV | 去重 `visitor_id` 数量 |
| 会话数 | 去重 `session_id` 数量 |
| 跳出率 | 仅含 1 次 pageview 的会话数 ÷ 会话总数 |
| 平均会话时长 | 每个会话 `max(ts) − min(ts)`，再对所有会话取平均 |
| 环比 | 本期值 vs 上一等长周期同值；上一周期为 0 时环比显示 `—` |
| 时间归属 | 一律使用**服务端落库时间**做日期归属与统计（客户端时间仅存作参考字段） |

## 5. 埋点协议摘要（详见 ARCHITECTURE.md 第 7 节）

上报端点：`POST /api/collect`，请求体为 JSON（以 `text/plain` 发送以规避跨域预检），字段：

`k`(站点公钥) / `e`(事件类型) / `vid` / `sid` / `url` / `title` / `ref` / `sw` / `sh` / `lang` / `tz` / `ts`

服务端负责：UA 解析、来源渠道分类、路径解析、IP 哈希（隐私化）后落库。

## 6. 非目标（本期不做）

- 实时在线人数、最近访问流
- 自定义事件 API 与 Web Vitals 采集
- 漏斗、留存、路径分析、用户画像
- 地理位置（IP 归属地）、邮件/定时报表、告警
- 多成员协作、权限分级、公开分享看板
- 收费、套餐、用量配额
